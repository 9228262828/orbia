# Orbia GitHub Pages

Static GitHub Pages files for Orbia.

## Files
- `docs/index.html`
- `docs/privacy.html`
- `docs/terms.html`
- `docs/style.css`

Contact: adrianpainting911@gmail.com

## Publish with GitHub Pages
1. Upload the `docs` folder to the repository.
2. Open repository **Settings → Pages**.
3. Under Build and deployment choose **Deploy from a branch**.
4. Select the branch containing these files.
5. Select the `/docs` folder and save.

## Release note
The privacy policy reflects the current Orbia implementation: offline-first
local storage, countdown/moment records, search, favorites, saved items,
delete functionality, and automatic archive behavior.

Review the policy before every release if you add accounts, cloud sync,
notifications, advertising, analytics, crash reporting, file/photo access,
location, or other third-party services.
